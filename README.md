# Norman Core SDK Overview

Norman Core SDK is the foundational layer that powers all Norman services.

It provides low-level, high-performance utilities used internally by Norman’s platform components, including HTTP communication, file streaming, socket encryption and retrieval of stored model data.

The Core SDK serves as the underlying library on which the higher-level Norman SDK is built. Developers who require finer-grained control when interacting with Norman services should use this SDK directly.

An example for a use case is uploading a model and actively polling for status flags (for example, every 5 seconds) to monitor processing progress.
